# Rust Arrow 53 → 59 fixture witness

The fixed binary fixtures under `tests/fixtures/arrow53` were generated by this
isolated Rust 53 producer. Their provenance records the exact source, lock,
executable and output hashes. The two public-reader tests exercise candidate
Arrow 59 against those retained bytes; generation alone proves no compatibility.

The isolated `[workspace]` producer pins Arrow array/schema/IPC and Parquet to
**=53.4.1** and never links candidate DAG/Arrow59 crates. It writes actual
`StreamWriter` / `ArrowWriter` bytes without rewriting IPC or Parquet. Fixed data
includes ordered noncontiguous IDs, two target columns, variable-length/empty
lists, nullable scores, cache/schema metadata and content/score fingerprints.
Payload values and expected contracts are deterministic. HashMap schema metadata
order may change byte hashes between generations; metadata order is not tested.

For an intentional fixture refresh, run once from the DAG root into a new audit
directory, review the resulting differences, and retain its provenance:

```sh
CARGO_TARGET_DIR="$AUDIT/arrow53-fixture-producer-target" cargo run --release --offline --locked --manifest-path scripts/arrow53-compat-fixtures/Cargo.toml -- "$AUDIT/arrow53"
```

`AUDIT` must be a fresh audit output root. Missing output parents are
created; the final `arrow53` directory must not exist. Run in a writable candidate
copy, never an immutable source freeze. An existing output directory is refused,
including after a partial failure: preserve failed outputs rather than rerunning
into them. Resolve/preserve the standalone Cargo.lock separately from the DAG
lock; never patch this producer onto Arrow59. Offline generation requires the
pinned crate archives and must fail if they are unavailable.

Retain the actual terminal generation/build log, standalone Cargo.lock, executed
`cargo metadata --offline --locked` proof showing every Arrow/Parquet dependency
is 53.4.1 and its registry checksum, source/manifest/producer executable SHA256,
and SHA256 of `provenance.json`. The producer records the lock/source/executable
hashes and exact hashes of its four output files, not a fabricated review result.
Externally bind this evidence to the reviewed source freeze and actual toolchain.
Version all five fixture/provenance files and the standalone lock before release,
then freeze their hashes. Tests read these fixed files; they never regenerate
fixtures, fall back to candidate59 writers, or skip absent prerequisites.

The two witnesses call public `predictions_from_arrow_ipc` and
`read_native_results`. Parquet additionally requires its real `created_by`

untouched. Run the two integration-test targets under candidate Arrow59 after
